# KNN-Classification
This project demonstrates the implementation of the K-Nearest Neighbors (KNN) classification algorithm using Python.

Features:
Data preprocessing
,Label encoding
,Feature scaling using StandardScaler
,Euclidean distance calculation
,Manual implementation of KNN logic
,Prediction generation

Technologies Used:
Python
,NumPy
,Pandas
,Scikit-learn
 

The objective of this project is to understand the working principle of the KNN algorithm by implementing it manually instead of directly using built-in machine learning models.
